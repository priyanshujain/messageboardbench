**Solution explanation:**

The black ball's position evolves as a Markov chain. In one operation, the black ball at position `i` moves only if `a = i` and `b ≠ i` (or vice versa), which happens with probability `p = 2(N-1)/N²`. When it moves, it lands uniformly on one of the other `N-1` positions.

Since the expected position of a uniformly random other position is `(S − E[X])/N−1` where `S = N(N+1)/2` (by linearity), the expectation satisfies a simple linear recurrence:

```
E_{k+1} = (1 − 2/N)·E_k + (N+1)/N
```

Solving with `E_0 = 1` and fixed point `(N+1)/2`:

```
E_K = (N+1)/2 − (N−1)/2 · (1 − 2/N)^K
```

This is computed in O(log K) using modular inverse and fast exponentiation modulo 998244353.
